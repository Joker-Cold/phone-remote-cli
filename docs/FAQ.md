# 常见问题

[← 回到首页](../README.md)

按遇到的现象查找。

**手机提示连不上。** 依次确认：手机上的 Tailscale 已连接，且和电脑登录的是同一个账号；电脑端“连接”页的状态是绿色；Windows 防火墙询问时选了“允许”（没选的话到“Windows 安全中心 → 防火墙 → 允许应用通过防火墙”里勾上 python）；Tailscale 的访问控制允许手机访问电脑的端口。电脑的 Tailscale 地址变了时需要重新扫码。

**提示“这台电脑的登录已失效”。** 电脑端换过密码、手机上退出过登录，或电脑端的登录记录被清掉后，App 保存的登录就不再有效。1.0.4 起 App 发现这种情况会回到工作台，点“重新扫码连接电脑”扫电脑窗口里的二维码即可，不需要手动输入密码，原来的名称会保留。

**电脑端提示“未检测到 Tailscale”。** 电脑上的 Tailscale 没有运行或没有登录。打开 Tailscale 并登录，几秒后电脑端会自动启动服务，不需要点“重新连接”。电脑端只认 Tailscale 自己的网卡，其他网卡上的地址即使在 `100.64.0.0/10` 范围内也不会使用。

**手机上同时要用别的 VPN。** Android 同一时间只能开一个 VPN，Tailscale 开着时其他 VPN 会被断开。需要两者同时工作时，可以在 Tailscale 的设置里调整，或在用 Phone Remote CLI 时切回 Tailscale。

**工作台里一个任务一直显示“已完成”。** 这个标记保留到你点开那个终端为止。在工作台点它，或在这台电脑的列表里点它，都算看过。

**列表里没有“新建 Claude Code”。** 按钮只显示电脑上能找到的工具。先在电脑的命令行里确认 `claude` 或 `codex` 能运行，再重新打开 Phone Remote CLI。

**输入后要等一下才显示。** 终端优先使用 WebSocket 持续连接，输入和输出实时传输，连续按键不用逐次等待上一条请求完成。延迟主要取决于手机到电脑的网络往返：Tailscale 能直连时最快，经它的中继服务器转发时会慢一些，可以在电脑上运行 `tailscale status` 查看到手机的连接是直连（direct）还是经中继（relay）。连接不支持 WebSocket 时会自动切换到 HTTP。

**电脑上打开着的对话，为什么有时不能直接在手机上继续？** 要在手机上继续，得先结束电脑上正在用这段对话的程序。电脑端只有在确认了是哪个进程在用它之后才会去结束，这时显示“在手机上继续”。由 Codex 桌面应用或编辑器打开着的对话，它们的后台可能同时管着好几段对话，手机不能替你关，所以会请你先在那个应用里结束；Codex 还可以“另开一份继续”，用 `codex fork` 带着此前的内容新开一段，之后各自继续。已经结束的对话用 `codex resume` 恢复。无论哪种情况，点开对话都能先看到它最近的内容，这一步不影响电脑上的程序。

**电脑上只开着一段对话，手机为什么还列出别的？** Codex 桌面应用或编辑器可能还占着以前的对话，另一个远程终端也可能在后台运行着。它们折叠在“被电脑上其它程序占用的对话”里，标着“被电脑上的应用占用”“被另一个远程终端占用”或“被电脑上的程序占用”，不算在电脑上打开着的数量里，程序也不会去结束它们。

**想在电脑上用手机开的终端，要交接吗？** 不用。0.8.0 起，在电脑端“活动”页双击那个终端，电脑上会打开一个窗口，里面就是同一个终端，手机和电脑都能看、都能输入。原来的“结束手机终端，在电脑的命令行窗口里接着用”还在，叫“转成独立窗口”，转之前会重新核对进程和对话编号，核对失败会保留原终端并说明原因。

**启动后马上结束。** 终端画面和退出代码会保留；检查画面中的 CLI 提示，例如登录状态、命令支持或工作目录。会话扫描遵循 `CODEX_HOME`，旧锁文件不会仅因存在而被显示为运行中。

**端口 8722 被占用。** 退出程序后，把 `%LOCALAPPDATA%\RemoteCli\config.json` 里的 `Port` 改成别的数字再打开。

**终端页为什么没有话筒按钮？** 话筒用的是手机系统自带的语音识别。很多国内品牌的手机没有这个组件，按了也不会有反应，所以 1.0.0 起在这样的手机上不再显示它。请点输入框，用输入法键盘上的语音键说话，效果是一样的。

**开了任务提醒却收不到通知，或者来得晚。** 先确认系统设置里允许了 Phone Remote CLI 的通知。1.1.0 起通知栏里不再有常驻的通知，App 由系统大约每分钟唤醒一次去查看，所以提醒会晚几十秒到一分钟，手机深度休眠时更久。有些手机不允许应用在后台被唤醒，需要在系统设置里允许 Phone Remote CLI 自启动，并把电池优化设为“不限制”。提醒只在 App 离开前台之后工作，并且只提醒离开之后新出现的情况。
